# data-warehouse-foundation
Learning project: Building a modern data warehouse step-by-step (Bronze/Silver/Gold) using SQL Server &amp; ETL pipelines

This repository documents my journey learning how to build a **data warehouse from scratch**.  

I'm following the excellent [SQL Data Warehouse Project](https://github.com/DataWithBaraa/sql-data-warehouse-project) tutorial by [DataWithBaraa](https://www.youtube.com/@datawithbaraa) to gain hands-on experience with real-world data engineering concepts.

---

## 🎯 What I'm Learning

- **Data Warehouse Architecture** – Understanding Bronze, Silver, and Gold layer design
- **ETL Development** – Building pipelines to extract, transform, and load data
- **Dimensional Modeling** – Creating star schemas with fact and dimension tables
- **SQL Development** – Writing complex queries and transformations
- **Version Control** – Managing projects with Git and GitHub

---

## 🗂 Project Structure

```
📁 data-warehouse-foundation/
├── datasets/       # Raw sample data (CRM, ERP)
├── scripts/        # SQL scripts for each layer
│   ├── bronze/     # Raw data ingestion
│   ├── silver/     # Data cleaning & transformation
│   └── gold/       # Scripts for analytical models
├── docs/           # My notes, diagrams, and references
└── README.md       
```
